Which AI models are genuinely great and free?

A source-based comparison of non-mainstream Chinese AI, international open-weight models, public free websites, free inference tiers, and local generation—designed to answer a specific question: what can you use without buying credits or connecting a billing account?

Executive finding

No single cloud workbench can reliably offer the strongest text, image, video and voice models forever, with unlimited use, no account, no key and no cost. Providers pay for inference, so hosted free access is normally rate-limited, promotional, account-gated or dependent on the model owner’s policy.

For a single online workspace, use the cloud model hub as the default: one OpenRouter account gives the page a unified, live catalogue of API-accessible models from Chinese and international providers. Direct official chat sites and public creative demos remain as fallbacks for proprietary features that are not exposed through that gateway. Local inference is optional and is not the main workflow.

What changed in the workbench: the cloud model hub is now the primary panel, before on-device inference and the creative demo list. It uses a user-authorized OpenRouter connection to load the current supported catalog in the page. The free text router is the default starting point; local AI has been moved into an optional collapsed panel.

1. Methodology

This is a desk-research study, not a claim that every model was personally benchmarked on the same hardware. It triangulates independent human-preference rankings, specialist image rankings, first-party model/runtime documentation, price and quota pages, and model licences.

Evidence stream A

Observed model quality

Text: Arena preference rankings, which aggregate blind human comparisons across real prompts. Image: Artificial Analysis’ open-weights text-to-image Elo based on pairwise human preferences. These measure different things and must not be mixed into one score.

Evidence stream B

Real free-use conditions

Official pricing, usage-limit, free-credit and hardware documentation determines whether a model truly avoids payment. “Free tier” is kept separate from “no key” and “unlimited”.

Scoring dimensions

Five separate tests

Quality: independent benchmark signal. Cash cost: €0 versus quota or paid credits. Setup: no account, simple sign-in, or API key. Integration: can it run inside this website? Use rights: licence and privacy caveats.

Important limitation

Benchmark rankings are not universal

Preference-based rankings favour what the evaluated community likes; coding, factuality, multilingual quality, long-context use, speed and prompt adherence can give different rankings. Free usage popularity is not a scientific quality score.

Cut-off: pages were reviewed on 22 October 2026. Free plans, queues, model IDs, quotas and licenses can change. Use the official source links to re-check current terms before relying on a service.

How to use the cloud-first workbench

This route sends prompts to hosted providers. You do not download models, need WebGPU or run a local inference engine. To unify model selection inside this page, you do need to authorize one gateway account; that does not mean you must buy credits.

01 · Connect

Open the cloud model hub

On the main workbench, click “Open cloud model hub”, then “Sign in & connect”. The OAuth flow authorizes your own OpenRouter account and returns you to the site. It is safer than pasting a key, and requests go from the browser to the gateway—not to this website's server.

OAuth connection guide ↗

02 · Stay free-first

Keep the free switch on

Leave “Prefer free text models only” checked. Start with “Free model router” for a $0-per-token response, or choose a specifically listed model whose current catalog price is $0. The free plan currently lists 25+ models across four providers and 50 requests/day; confirm current rules on the pricing page.

Official pricing and limits ↗ · Free model list ↗

03 · Pick a model

Choose from live options

Once connected, the picker retrieves the current model catalog. Filter to free text models and search for a Chinese or non-mainstream family where available. Use specific provider/model IDs when you need a consistent model rather than the randomized free router.

04 · Run a task

Chat, code or research

Enter the task, choose Chat / Coding / Research, then run it. Use concise requirements, output format and acceptance criteria. The optional web-search tool can help with current research, but you should review its terms and any price shown before running a tool-enabled request.

05 · Generate media

Check pricing separately

The “free text models only” filter does not guarantee free images, video or speech. Those endpoints may require paid credits. When you want no API key, switch to the public Qwen Image, Wan, LTX or Qwen TTS demo tabs; those can have queues and shared daily GPU limits.

06 · Know the boundary

Not literally every model

This gateway combines models its API exposes. Some proprietary web-only agents, subscription features, regional products and private endpoints cannot be added to the same chat selector without a supported API and your provider authorization. The workbench's model catalogue therefore links to official websites as a second route.

A useful prompt recipe

Goal + context + output + style + constraints.
Photography example: “Give me 6 unusual photographic ideas for Aquileia, Italy. For each: exact subject, where to stand, framing with an 18–150 mm lens, best light, mood and one alternative composition. Prioritise overlooked details over obvious landmarks. Mark unverified locations as leads, not facts.”

Research example: “Compare the latest Chinese open and hosted coding models for a small web app. Cite official model cards and current pricing, separate free endpoints from paid API access, and say which facts are uncertain.”
Cost and privacy boundary: free text inference has a quota, not an unlimited guarantee. Paid models or non-text endpoints can incur cost if you authorize and select them. Cloud prompts are processed by OpenRouter and the upstream provider; avoid sending sensitive material unless you accept those services' privacy terms.
