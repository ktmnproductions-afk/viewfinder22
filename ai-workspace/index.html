Pick a tool, make something.

Start with the cloud model hub for online chat and coding. Use the public creative demos for images, motion and voice. Your browser does not need to download or run a model; a free gateway account is required to unify API-accessible chat models.

FREE-FIRST
ACCESS ✳
01 / THINK✳

Ask, plan, brainstorm

Use the hosted model picker to compare Chinese and international models in one chat interface. Choose the free router first; use web search for current questions when suitable.

02 / BUILD⌘

Make or fix a website

Use the cloud catalog to choose a coding model such as a Qwen Coder, DeepSeek or GLM variant. No local installation is needed; the model itself runs with the provider.

03 / FRAME▧

Create an image

Open Qwen Image 2.1 or the faster Turbo variant below. Include subject, composition, lighting, texture, aspect ratio and what to avoid.

04 / MOVE▷

Animate a still image

Try Wan 2.2 or LTX 2.3. Upload one strong image and describe one camera move plus one subject action, not a whole movie at once.

05 / LISTEN♫

Make a voiceover

Paste a clean script into Qwen3 TTS, select language and voice, generate a sample, then download the audio if the demo exposes the result.

06 / PROTOTYPE▤

Turn an idea into a page

Ask for one landing page with a clear audience, content and style. Inspect the preview, then refine one thing at a time.

1
Connect once

Choose “Connect AI models” and sign in to OpenRouter. A free account is enough to start with its free model tier; no local model download is needed.

2
Use a clear brief

Say what the output should be, who it is for, the style, constraints and format. A concrete prompt beats “make it better”.

3
Iterate and verify

Ask for one improvement at a time. For current facts, use the web-search option or open the official model site. Check charges before choosing paid endpoints or media-generation APIs.
