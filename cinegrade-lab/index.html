How to use the recipe

An edit order that keeps the look controlled
  1. Correct exposure and white balance first. Don't use a creative grade to fix a badly exposed frame.
  2. Set Shadows, Midtones and Highlights with the hue/saturation/luminance values above.
  3. Set Blending and Balance; if skin or neutral surfaces turn too colorful, lower wheel saturation before changing the palette.
  4. Apply the Basic-panel finishing values, then tune per photo. A preset should unify a series—not make every light source the same color.

Lightroom Color Grading uses hue and saturation to tint tonal ranges; blending controls overlap, while balance shifts emphasis between shadows and highlights. Output varies with the image, profile, lighting and existing edits.
